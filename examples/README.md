# Examples (legacy)

Early demonstration scripts from before the Threat Analysis Console. They are kept for reference only, are not part of the test suite, and are not needed to use the project.

| File | Description |
|---|---|
| `demo_phase1_engine.py` | Early asyncio engine demonstration. |
| `demo_phase2_events.py` | Early event system demonstration. |
| `demo_phase2_events_simple.py` | Simplified version of the above, without Orekit. |

To use the simulator, start the console and run the tests as described in the main [README](../README.md).
